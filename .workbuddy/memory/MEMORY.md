# 项目长期约定

- 现场设备反馈优先采用后端 S7 直连，以 IP、Port、Rack、Slot 建立长连接；Redis 保留为业务/可选数据链路，不再默认作为 PLC 实时反馈的唯一入口。
- S7 监控接入保持只读，不从孪生页面直接写 PLC；真实连接失败时不得自动回退为模拟数据。
- 浏览器不直接连接 PLC，由共享后端网关统一采集、重连和维护设备状态。
- 同一台 PLC 只维护一条 S7 长连接，可挂载多个 DB 块；每个块独立配置周期、启停、解析模板和错误状态，单块失败不得拖垮其他块。
- S7 配置按版本化“设备→DB 块”结构保存，升级时兼容旧版单 DB 配置；设备列表只回状态摘要，详情接口才回变量和原始字节。
- 平台账号使用 MySQL + PBKDF2 密码哈希 + 数据库会话；角色固定为 viewer / engineer / super_admin，客户只看整体视图、看板和脱敏遥测，设备协议与连接仅 engineer/super_admin。
- 本机数据库密码只放 gitignored 的 `appsettings.Local.json`，服务器通过 `MySql__*` 环境变量配置连接与连接池，发布产物不得携带本机密钥。
