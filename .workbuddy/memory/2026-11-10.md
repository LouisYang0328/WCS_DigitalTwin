## 前端性能优化（index.html 三维页）

实测基线（Chrome headless + SwiftShader，1600×900）：
- DOMContentLoaded 2430ms，首屏长时间白屏（16 个同步脚本 + 同步构建场景）
- 每帧约 194 次 document.getElementById（showDeviceLabels 约 169 次/帧）
- 每帧 ~1397 draw call（SSAO 3 趟 + 阴影 1 趟），13 FPS
- 每 420ms 全量 innerHTML 重建巷道列表/线路图并重绑监听

已改：
1. index.html 改为「两帧后按序注入脚本」的引导加载器，首屏 FCP 384ms；echarts 改为打开看板时按需加载（省 1MB 首屏解析）。
2. twin-scene.js：el() 加缓存；复选框状态用 uiFlags 镜像（新增 #showDeviceLabels 监听）；列表渲染改签名比对 + 事件委托；阴影贴图按画质隔帧刷新（high 1 / balanced 2 / performance 3）；画质档位约束 DPR（1 / 1.25 / 1.5）；低帧率自动降档（用户手动选过画质则锁定）；页面隐藏时停 rAF；首屏加载层。
3. twin.css 增加 #boot 加载层样式。

结果：draw call 1397→733（流畅档），getElementById 194/帧→0，首屏 384ms 可见，场景就绪约 2.9s（软件渲染）。
新增只读调试入口 window.__twinDebug。

## 前端迁移到 Vue 3 + Vite（A 路线，第一轮：壳与面板组件化）

新增 web/ 工程：Vite 6 + Vue 3.5，`base: './'`，`build.outDir = ../app`、`assetsDir: 'bundle'`。
vite.config.js 自带 workspaceAssets 插件：dev 时把 `/assets/*` 直接映射到仓库根 assets/，不起网关也能调界面。

组件拆分（全部保持原有 id/class，twin-scene.js 无需改选择器）：
BootScreen / TwinStage / TopBar / LeftPanel / RightPanel / DataDashboard / SceneTools。
web/src/engine/load-engine.js 串行注入三维引擎脚本，由 App.vue 在 onMounted 后调用（保证面板已上屏）。

网关：Program.cs 把 app/ 挂到站点根（bundle 在 /bundle），首页优先 app/index.html、缺失时回退根 index.html；
旧页保留在 /legacy.html。echerts 懒加载路径改为 `/assets/echarts.min.js`（原来相对路径在 /app 下会 404）。

start.ps1 重写：UTF-8 BOM + 控制台 UTF-8 输出；参数 -ListenUrl / -SkipWebBuild / -NpmRegistry；
node_modules 缺失时 npm install，然后 npm run build 到 app/，构建失败只告警不阻断并回退旧页。

验证（Playwright + 网关 5080/5082）：FCP 392~700ms，KPI 2000、152 台设备、5 条巷道，楼层切换/沉浸/开关/搜索/看板 7 图懒加载正常，旧页与 devices.html 正常，控制台无报错。
注意：npm 默认源 registry.npm.taobao.org 在本机被拦截（403），需用 https://registry.npmjs.org/。

## 启动/停止脚本补齐（端口占用与 Ctrl+C 问题）

现场反馈「跑 start.ps1 后 PLC 连接失败就直接退出，没法 Ctrl+C」。实测根因：5080 已被上一个实例占用，
dotnet 绑定失败抛异常退出，窗口一闪而过；控制台里滚动的是网关正常的 S7 重连告警（每设备第 1/10/20… 次才打印一次），并非退出原因。

改动：
- 新增 stop.ps1：按端口找监听进程并结束，输出已停止的进程名/PID，最后报告端口是否释放；
  兼容没有 Get-NetTCPConnection 的环境（退回 netstat 解析）；-ListenUrl 可指定端口。
- start.ps1 增加端口预检：被占用时不再让 dotnet 崩，而是列出占用进程并给三条出路
  （.\stop.ps1 / -ForceRestart / 换端口），退出码 1；新增 -ForceRestart 自动接管旧实例。
- 启动横幅补充「按 Ctrl+C 停止」与「S7 connection failed 属正常重连」的说明。
- stop.ps1 与 start.ps1 都写 UTF-8 BOM + 统一控制台 UTF-8 输出。

验证：占用时二次启动 → 明确提示并 exit 1；stop.ps1 → 停止 WcsGateway 且端口释放；-ForceRestart → 自动替换后 /index.html 返回 200。
